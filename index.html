Global Map of Anticipatory Action Protocols

About this map

This dashboard consolidates FAO and inter-agency Anticipatory Action (AA) protocols worldwide into a single, structured, comparable dataset — one row per country and hazard (and coordinating agency, where more than one agency runs a separate protocol for the same hazard).

Each protocol's trigger mechanism, thresholds, financing and coverage fields are extracted directly from the source AA framework or protocol document for that country and hazard — never inferred or estimated. Where a document does not specify a field, this is disclosed explicitly ("Not specified in the reviewed corpus") rather than left silently blank, and each record carries a Reading Confidence tier (High / Medium / Low) reflecting how completely the source document was reviewed.

Coverage is intentionally uneven: activity-level implementation timelines (Gantt) and full AA Info detail are available for the protocols where the source documentation supports that level of detail, and will grow as more protocols are reviewed. This is a living reference tool, not a final or exhaustive record.
